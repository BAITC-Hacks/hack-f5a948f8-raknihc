# Career Quest — AI-навигатор развития сотрудника

Проект команды **Raknihc** для HackAlem AI. Выбран кейс **Career Quest**, заказчик — АО «Народный Банк Казахстана».

## Задача

Помочь сотруднику понять, какие навыки нужны для следующего грейда, выбрать полезную активность и увидеть результат обучения. HR получает обзор дефицитов компетенций и участия в развитии.

## Текущий статус

Реализован начальный Python-движок: восстановление навыков, расчёт дефицитов, фильтрация и ранжирование мероприятий, объяснения по правилам и симуляция прогресса. Контракт и ограничения: [docs/api-contract.md](docs/api-contract.md). Интеграция с LLM, полная проверка схем импорта, HR-агрегации и веб-приложение пока не реализованы. Основной сценарий ниже описывает целевой объём.

Проверка движка из корня репозитория: `python -m unittest discover -s tests -v` (Python 3.10+, без дополнительных зависимостей). Для работы с исходным датасетом поместите его файлы в `data/private/career_quest_dataset`; папка исключена из Git.

## Основной сценарий

1. Открыть профиль сотрудника и требования следующего грейда.
2. Получить 1–3 доступные активности с объяснением на основе дефицитов, критических навыков и истории участия.
3. Посмотреть ожидаемое изменение навыков после активности.
4. Отметить выполнение и получить пересчитанные навыки и рекомендации.
5. Открыть HR-обзор дефицитов и участия.

Для проверки жюри предусмотрена загрузка дополнительных профилей и истории в формате стартового датасета.

## Планируемая архитектура

- **AI engine:** загрузка и проверка схемы, восстановление навыков, анализ дефицитов, отбор кандидатов, многофакторное ранжирование и LLM-объяснения.
- **Backend:** Python/FastAPI, SQLite, API, сессии и разграничение доступа сотрудник/HR.
- **Frontend:** React, TypeScript и Vite; кабинет сотрудника, рекомендации, симуляция прогресса и HR-экран.

Сервер передаёт движку актуальные данные; движок возвращает расчёты и не управляет сохранением в базе. Числовые изменения навыков рассчитываются кодом по правилам датасета.

## Данные

Стартовый кит содержит 200 синтетических профилей, 60 навыков, 32 профиля требований к ролям и грейдам, 40 мероприятий и 2 743 записи участия. Расчётная дата — **2026-10-01**.

Датасет используется в рамках хакатона. Исходные данные в этот коммит не включены. Особенности обработки описаны в [docs/dataset-notes.md](docs/dataset-notes.md).

## Установка и проверка

Движок доступен как Python-модуль; пример вызова приведён в [контракте](docs/api-contract.md). Команда запуска веб-приложения будет добавлена участником, отвечающим за приложение.

Целевой проверочный сценарий: импорт нового профиля → рекомендация с проверяемыми причинами → выполнение активности → обновление навыков и HR-аналитики. Дополнительно проверяются повторное выполнение и запрет доступа к чужим данным.

## Ограничения и внешние сервисы

- Конкретная LLM и внешний API ещё не выбраны и не подключены.
- Прогресс означает соответствие требованиям по навыкам, а не гарантию повышения.
- Публичные рейтинги сотрудников и баллы за обязательные процессы не предусмотрены.
- API-ключи должны храниться в переменных окружения; `.env` исключён из Git.
- Развёрнутой версии пока нет.
